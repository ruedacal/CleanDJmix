# CleanDJmix PRO - macOS App Icon Package
Created by Victor Rueda

## Contents of this package:
1. `AppIcon.appiconset/`: Ready to be dropped directly into your Xcode project's asset catalog (`Assets.xcassets`). Contains all required macOS icon resolutions (16x16 up to 1024x1024@2x).
2. `icon_1024x1024.png`: High-resolution master PNG image (1024x1024 px) for App Store submission and promotional use.
3. `CleanDJmix_PRO_Logo.svg`: Vector SVG template embedding the logo design and typography.

## How to use in Xcode (macOS App):
1. Open your Xcode project.
2. Navigate to `Assets.xcassets`.
3. Replace or drag-and-drop the `AppIcon.appiconset` folder into `Assets.xcassets`.
4. In your Target settings under `General` -> `App Icons and Launch Screen`, make sure `App Icon Set` is set to `AppIcon`.
