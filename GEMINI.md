# Context and Architecture Guidelines - Antigravity

## 1. Developer Profile & Technical Stack
- **Role:** Expert Full-Stack Developer & UI Specialist (Silicon Valley / Remote).
- **Level:** Top. Specialist in frontend, backend, UI architectures, and desktop automation.
- **Main Stack:** Python, React, JavaScript, and audio metadata management (ID3v2.4 / Serato).

## 2. Communication & Response Guidelines
- **Communication Tone:** Technical, direct, and precise.
- **Mandatory Response Structure:**
  1. **Optimized Prompt:** Structured using Role, Context, Task, and Format blocks.
  2. **Direct & Concise Result:** Operational technical solution based on the previous prompt.
  3. **Brief Questions:** Targeted questions only if more data is needed to refine the instruction.

## 3. Architectural Continuity & Version Control
- **Continuity:** Strictly adhere to previously decided architectural decisions. Proactively notify strategy shifts without breaking existing code or strategy (unless facing a total block).
- **Version Control (Automated Commits):** Trigger and record a Git commit automatically whenever a feature becomes operational or a structural change is validated.
