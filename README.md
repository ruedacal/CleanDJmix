# CleanDJmix PRO 🎧✨

**CleanDJmix PRO** es una aplicación de escritorio avanzada desarrollada en Python y diseñada específicamente para DJs. Permite automatizar la limpieza de nombres, el etiquetado inteligente de metadatos ID3, la clasificación por géneros musicales mediante el algoritmo de Ishkur, el recorte de silencios físicos y el rescate acústico mediante huella digital (Shazam).

## Características Principales 🚀
- **Interfaz Rekordbox Style:** Diseño oscuro y profesional optimizado para DJs.
- **Análisis Híbrido y Estándar:** Limpieza y reescritura de metadatos con soporte para Discogs API.
- **Rescate Shazam (Audio Fingerprinting):** Identificación automática de pistas fantasma o corruptas a través de su onda de audio.
- **Análisis Acústico Profundo:** Extracción de BPM, cálculo de niveles de Energía (%) y Groove (%), y recorte de silencios iniciales.
- **Sistema de Telemetría Local:** Registro de errores limpio en archivos de log para facilitar la colaboración de la comunidad.
- **Soporte Multiplataforma / macOS:** Estabilidad garantizada frente al sistema de ahorro de energía de Mac.
